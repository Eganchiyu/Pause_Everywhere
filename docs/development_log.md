### 2024-01-10

#### [功能] 动态视觉特效系统
**提交**: `feat(effects): 添加动态视觉特效系统`

**变更内容**:
- 实现 CRT 扫描线效果（30FPS 动态滚动）
- 实现赛博故障风 Glitch 效果（随机撕裂带）
- 优化 `GaussianProcess.cs` 架构，分离底图生成和特效应用
- 添加 `DynamicEffectTimer` 定时器控制特效渲染

**技术细节**:
- 使用 `unsafe` 指针直接操作图像内存
- CRT 效果通过偏移扫描线实现
- Glitch 效果通过随机通道偏移实现
- 定时器间隔 33ms 约 30FPS

**性能影响**:
- CPU 占用增加约 5-10%
- 内存使用稳定
- 视觉效果流畅

### 2023-12-28

#### [功能] 低分辨率差分检测
**提交**: `feat(diff): 实现低分辨率差分检测算法`

**变更内容**:
- 创建 `LowResDiff.cs` 模块
- 实现 64x36 低分辨率差分算法
- 使用 `unsafe` 指针优化性能
- 缓存上一帧灰度数据

**算法流程**:
1. 捕获屏幕并缩放到 64x36
2. 转换为灰度图
3. 与上一帧计算差分能量
4. 能量超过阈值则认为屏幕变化
